# Callirra · organization profile & community files

This is the special `.github` repository: GitHub reads the files here for **every**
repository in the [callirra-ai](https://github.com/callirra-ai) organization.

| Path | Role |
|---|---|
| [`profile/README.md`](profile/README.md) | Renders as the organization page → [github.com/callirra-ai](https://github.com/callirra-ai) |
| [`profile/images/`](profile/images) | Images used by the organization page (referenced with relative paths) |
| [`SECURITY.md`](SECURITY.md) | Security policy inherited by repositories that have none of their own |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Default contribution guide for this organization |

## Editing the organization page

1. Edit `profile/README.md` — GitHub renders it directly, there is no build step.
2. Put any new image in `profile/images/` and reference it with a relative path (`images/foo.jpg`), so the page never depends on an external host.
3. Open a pull request; the change reaches the organization page as soon as it is merged into `main`.
